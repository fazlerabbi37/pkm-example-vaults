# Literature note: OpenWrt Wiki — ImageBuilder
Source: openwrt.org/docs/guide-user/additional-software/imagebuilder
Captured: 2026-08-20

- ImageBuilder pre-compiles, only assembles packages -> fast rebuilds
- Needs ~2GB RAM on build host
- Own words summary: it's a firmware assembler, not a compiler.
