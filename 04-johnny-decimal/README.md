# Johnny.Decimal Vault
10 AREAS (10-19, 20-29...) each holding max 10 CATEGORIES,
each holding numbered notes (11.01, 11.02...).
An ID is assigned once, never reused, never renumbered.
You keep a 00.00-index so IDs are citable: "that's in 12.03".
Strength: zero ambiguity about where things go. Weakness: rigid.
